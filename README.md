## Canonical rules

- `Core/` is the executable system core.
- `Codex/` contains semantic and operational knowledge.
- `EchoS/` is the EchoS system surface.
- `Archive/` is the canonical `Archive://` project archive.
- `Systems/` contains major MythOS subsystems.
- `Interfaces/` contains interaction surfaces.
- `Artifacts/` contains named project artifacts and inventions.
- `Modules/` contains independent capabilities.
- `Protocols/` contains cross-system procedures and contracts.
- `docs/`, `scripts/`, `tests/`, and `tools/` support engineering.

This hierarchy is authoritative. Application frameworks are implementation details and do not define the MythOS root.
