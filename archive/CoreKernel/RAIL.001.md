# Rail.001 — Canonicalization

**Status:** active

**Anchor:** MythOS

## Intent

Establish one authoritative repository boundary for MythOS software, Archive:// records, and reusable runtime primitives.

## Initial state

- Canonical repository: `IDevSU-source/MythOS`
- Application lineage: `IDevSU-source/MythOS-HackTheWorld`
- Archive lineage: `IDevSU-source/Archive`
- First kernel package: `packages/core`

## Next promotion targets

1. Codex schema and loader.
2. Archive record indexing and provenance.
3. Mobile application migration under `apps/mythos-mobile`.
4. Shared UI and terminal/HUD primitives.
5. CI validation and release pipeline.
