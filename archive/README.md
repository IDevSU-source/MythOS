# Archive://

The canonical MythOS knowledge namespace.

```text
Archive://
├── CoreKernel/
├── Codex/
├── Pleroma/
├── AeonAwakening/
├── Aeons/
├── JournalEntries/
├── OriginFlame/
├── TemporalRunes/
├── Modules/
├── MythOS_UI/
└── Experiments/
```

`archive/` stores durable project records. Runtime code belongs under `packages/` or `apps/`; records should not become hidden implementation dependencies.

Use stable paths and preserve provenance when migrating material from earlier MythOS repositories.
